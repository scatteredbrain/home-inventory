# Home Inventory Organizer

A simple web app for tracking where things are in your home.

## Features

- **Rooms & Sub-rooms** - Create rooms (Bedroom, Kitchen, etc.) and nest sub-rooms within them (e.g., Bedroom > Walk-in Closet)
- **Containers & Sub-containers** - Add furniture and storage to any room, with unlimited nesting (e.g., Dresser > Top Left Drawer)
- **Items** - Add, rename, and delete items in any container
- **Search** - Type an item name to instantly find it and see its full location path
- **Persistent** - All data is saved in your browser's localStorage

## Usage

Open `index.html` in your browser. Everything is self-contained in that single file — no install, no server, no dependencies.
